# LEXIRUN

A word platformer where letter blocks are the puzzle. Play it, and install it on your phone:
https://lexirun-game.github.io/

On iPhone: open it in Safari, tap Share, then Add to Home Screen.
On Android: open it in Chrome, tap the menu, then Install app.
